
# ☕ Brew Haven – Coffee Shop Website

A modern, responsive coffee shop website built using HTML5, CSS3, Bootstrap 5 and JavaScript.

## 🌟 Project Overview

Brew Haven is a coffee shop website concept designed to give visitors a welcoming online experience. Visitors can explore the café, browse drinks, read customer reviews and find contact information.

## 🚀 Features

- Responsive navigation bar
- Attractive homepage and hero section
- About Us section
- Coffee menu with product cards and prices
- Category-based menu filtering
- Add to Cart functionality (demo)
- Dynamic cart count and total price
- Customer reviews section
- Contact form with client-side feedback
- Mobile-friendly design

## 🛠️ Technologies Used

- HTML5
- CSS3
- Bootstrap 5
- JavaScript
- Google Fonts
- Unsplash Images

## 💻 How to Run

1. Clone this repository:

   `git clone https://github.com/vagulapuramridhi08-art/brew-haven-coffee-shop.git`

2. Open the folder in Visual Studio Code.
3. Open `index.html` using Live Server.
4. View the website in your browser.

## ⚠️ Project Note

This is a frontend-only demonstration. The cart and contact form are not connected to a backend, database or payment system.
